# 🎉 Trivia Game

Welcome to **Trivia Game**, a fun and interactive game to test your knowledge! Choose a category, answer multiple-choice questions, and see how far you can go. But beware—you only have 3 lives to prove your trivia mastery!

---

## 🚀 Features

- 🏆 Track your score as you play.
- ❤️ 3 lives to keep the challenge exciting.
- 🌟 Multiple categories to choose from.
- 📱 Fully responsive and mobile-friendly.
- 🎨 Elegant design with animations using Tailwind CSS.

---

## 🛠 Installation

Follow these steps to set up the project on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/trivia-game.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd trivia-game
   ```
3. **Install dependencies:**
   ```bash
   npm install
   ```
4. **Start the development server:**
   ```bash
   npm start
   ```

Your application will be available at `http://localhost:3000`.

---

## 🎮 How to Play

1. **Choose a category:**  
   Select a category from the list to start the game.

2. **Answer questions:**  
   A question with multiple-choice answers will appear. Click on your answer to submit it.

3. **Scoring:**  
   - Correct answers increase your score by 1.  
   - Incorrect answers cost you one life.  

4. **Lives:**  
   - You start with 3 lives, represented by ❤️ emojis.  
   - Lose all lives, and the game is over.

5. **Game Over:**  
   Once the game ends, you can view your score and restart by clicking the **Play Again** button.
